# Dart From Zero to Hero 🚀

A practical and example-driven journey through the **Dart programming language**, starting from the fundamentals and gradually moving toward Object-Oriented Programming and asynchronous programming.

This repository is created for learning Dart through simple, focused, and runnable examples.

---

## 📚 What You Will Learn

### 🟦 Dart Fundamentals

- Variables and data types
- `var`, `dynamic`, `final`, `const`, `late`
- Null Safety basics
- Lists and Maps
- Operators
- `if / else`
- `switch`
- Loops
- `for`, `while`, `do-while`, `for-in`
- Functions
- Optional parameters
- Named parameters
- `required`
- Arrow functions
- Anonymous functions
- Console input/output
- `dart:io`
- Building a simple CLI calculator

---

### 🟪 Object-Oriented Programming

- Classes and Objects
- Fields and Methods
- Constructors
- Named Constructors
- Redirecting Constructors
- `this`
- `super`
- Inheritance
- `extends`
- Method Overriding
- Polymorphism
- Abstract Classes
- Abstract Methods
- Interfaces
- `implements`
- Encapsulation
- Private Members
- Getters and Setters

---

### 🟩 Mixins

- Creating Mixins with `mixin`
- Using Mixins with `with`
- Multiple Mixins
- Mixin restrictions with `on`

---

### ⚡ Asynchronous Programming

- Synchronous vs Asynchronous execution
- `Future`
- `async`
- `await`
- `.then()`
- `catchError()`
- Delayed asynchronous operations

---

### 🌊 Streams

- `Stream`
- `async*`
- `yield`
- Asynchronous Streams
- `StreamController`
- `stream.listen()`
- `StreamSubscription`
- Adding events with `add()`
- Closing Streams

---
